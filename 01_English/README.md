## 维护约定

1. **新知识点** → 进 `知识库/` 对应主题文件，末尾标来源日期。
2. **自己卡住的点** → 进 `薄弱点追踪.md`，用 1–5 级记录掌握度。
3. **每日过程** → 进 `Daily/`，保留原始，不回头改写。
4. **不确定的内容** → 放 `知识库/00_导读与索引.md` 的「待补原文」，不猜。
5. 知识库解决「知道」，薄弱点追踪解决「掌握」，两边不要混。
