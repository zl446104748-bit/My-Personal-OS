# 俚语、文化与词源

> 这一册解决「每个词都认识，但整句不懂」的问题。俚语先记语气和使用场合，再记意思。

---

## 一、俚语与口语表达

### knockoff / knock off
- 意思：仿制品；动词 `knock off` = 快速仿制，也可指「下班、收工」。
- 词源：19 世纪 `knock off` 有「快速做完」的意思，后来引申为「照着样子快速做出来」，再变成「仿货」。
- 语气：口语，略带贬义；`knockoff` 不一定违法，`counterfeit` 才是法律意义上的伪造。
- 例句：This is a knockoff, not the real thing. 这是仿的，不是正品。
- 来源：2026-11-05

### catfish
- 意思：鲶鱼；网络交友诈骗（用假照片/假身份骗感情）。
- 词源：2010 年纪录片《Catfish》。片中主人公的妻子在网上恋爱，对方是假的；片尾用「鲶鱼在鳕鱼群里搅动，让鳕鱼保持鲜活」作比喻——有人专门在关系里搅动、操控。
- 用法：`catfish sb` 骗某人；`I got catfished.` 我被网骗了。
- 语气：现代网络词，正式写作可用「online romance scam」替代。
- 来源：2026-11-05

### hip
- 意思：时髦的、懂行的。
- 词源：爵士乐时代俚语 `hep`（「懂的、跟得上的」），后来变成 `hip`；`hipster` 原指懂爵士的人，现在指复古文艺青年。
- 例句：He's pretty hip for his age. 以他的年纪来说，他挺潮的。
- 来源：2026-11-05

### play it by ear
- 意思：走一步看一步、见机行事。
- 词源：音乐里 `play by ear` 指不看乐谱、凭听觉即兴演奏；没有「乐谱」就等于没有既定计划，于是引申为「看情况再决定」。
- 例句：We'll play it by ear. 到时候看情况。
- 来源：2026-09-29

### kick ass
- 意思：很厉害、干得漂亮；形容词 `kick-ass` = 超强的。
- 语气：粗俗度中等，朋友间夸人很自然；正式场合换成 `do a great job`。
- 例句：She kicked ass in the interview. 她面试表现超棒。
- 来源：2026-11-03

### suck
- 意思：吸、吮；（口语）很糟。
- 双义：字面 `suck the juice` 吸果汁；口语 `This sucks.` 这太糟了。
- 例句：That sucks. 太惨了。 / `sucks to be you` 你惨了（带调侃）。
- 来源：2026-11-03

### chrome off a trailer hitch
- 意思：字面「把拖车钩上的镀铬层舔掉」；夸张的成人向俚语，形容某人极具吸引力/嘴上功夫了得。
- 语气：粗俗玩笑，不适合正式场合；知道意思即可，不必主动使用。
- 来源：2026-11-03

### throw the kids away
- 意思：字面「把孩子扔掉」；英式幽默里的夸张自嘲，实际是「带娃太累，开玩笑说想把他们扔了」。
- 语气：轻松玩笑，不能按字面理解。
- 例句：Some days you just want to throw the kids away. 有些日子真想把孩子扔了（开玩笑）。
- 来源：2026-11-05

### all good in the hood
- 意思：街坊邻里一切都好。
- 文化：`hood` = neighborhood，常见于 AAVE（非洲裔美国人英语）和说唱文化；押韵、轻松。
- 例句：All good in the hood. 这儿一切都好。
- 来源：2026-11-05

### LMAO / hilarious / crack sb up
- `LMAO`：laughing my ass off，笑死，网络缩写，正式场合不用。
- `hilarious`：非常好笑，比 funny 程度强。
- `crack sb up`：把某人逗笑；也可指「崩溃」，看语境。
- 例句：That video cracked me up. 那个视频把我笑崩了。
- 来源：2026-11-05

### lingo / slang / idiom / colloquialism
- **lingo**：某个圈子/行业的行话，或对「外语」的随口称呼。
- **slang**：俚语，非正式、常随年代变化。
- **idiom**：习语，固定搭配，意思不能从字面推。
- **colloquialism**：口语表达，正式度低但不一定是俚语。
- 例句：Learn the lingo before you join the group. 进圈子前先学会行话。
- 来源：2026-11-05

### get lost
- 意思：迷路；滚开（粗鲁）。
- 语气：`Get lost!` 很冲；`I got lost` 只是迷路。
- 例句：I got lost downtown. 我在市中心迷路了。
- 来源：2026-11-05

## 二、文化与背景知识

### Atlantic / Atlas / Atlantis / Pacific
- **Atlantic**：大西洋，源自希腊神话巨神 **Atlas**（阿特拉斯），传说他撑起天空，山脉/海洋以他命名。
- **Atlas**：也指「地图册」，因为早期地图集封面常画阿特拉斯托地球。
- **Atlantis**：亚特兰蒂斯，柏拉图笔下沉入海底的传说岛屿，和 Atlantic 同源但不是一个概念。
- **Pacific**：太平洋，麦哲伦船队因海面平静命名为 `Mar Pacifico`（平静之海）。
- 记忆：Atlantic 是「阿特拉斯之海」，Atlantis 是「传说中的岛」，Pacific 是「平静的海」。
- 来源：2026-11-05

### bull market / bear market
- **bull market**：牛市，价格上涨、情绪乐观。
- **bear market**：熊市，价格下跌、情绪悲观。
- 词源说法之一：公牛攻击时从下往上顶，熊攻击时从上往下拍；对应价格的上升与下降。另有说法与 18 世纪「未捕到熊就先卖熊皮」的谚语有关。
- 例句：Gold often rises in a bear market. 熊市里黄金往往上涨。
- 来源：2026-11-03

### A-levels（英国高中课程）
- 全称 General Certificate of Education Advanced Level，英国高中最后两年的课程与考试，通常选 3–4 门，用成绩申请大学。
- `do A-levels` = 读 A-level 课程（`do` 在英式口语里常指「读/学某课程」）。
- `do A-levels online` = 线上修读课程，但考试仍要去官方考试中心线下参加。
- `sixth-form college` = 英国专门读 A-level 的高中阶段学院。
- 来源：2026-09-29

### exclusive dating（专一交往）
- `dating exclusively` / `exclusive` 在恋爱语境里指「只和对方一个人约会」，是确定关系前后的阶段。
- `We're exclusive.` 我们只和彼此交往。
- 文化差异：英语里 `dating` 不一定等于正式恋爱，`exclusive` 才是排他承诺。
- 来源：2026-11-05

### 残障与护理语境词汇
- `disability community`：残障群体。
- `walker`：助行器；`wheelchair` 轮椅；`caregiver` 照护者。
- `transfer`：把病人从床转移到轮椅/椅子，是护理动作的高频词。
- 文化：英语里谈残障更常用 `person with a disability`（人本位表述），少用带贬义的旧词。
- 来源：2026-11-05

### dim sum（粤语借词）
- 英文直接从粤语「点心」（dim2 sam1）借来，指广式早茶点心。
- 一般作集合名词，不加复数 `-s`；`dim sums` 是非标准写法。
- 类似借词：`kung fu`（功夫）、`tofu`（豆腐）、`wok`（锅）。
- 来源：2026-09-29

### vlog 文化
- `vlog` = video blog，第一视角记录个人真实生活；和普通短视频的区别是「记录我的经历」，带叙述和感受。
- `vlogger` 视频博主；`vlogging` 拍 vlog。
- Emma Chamberlain 是典型代表：语速快、大量 `like / you know` 填充词、自嘲式幽默，适合练真实口语，但不太适合当标准发音教材。
- 来源：2026-10-16、2026-11-03

## 三、《See You Again》逐句与文化背景

> 背景：电影《速度与激情 7》片尾曲，献给已故演员 Paul Walker。歌词大量使用口语缩写和俚语，适合练「连读 + 情感语调」。

### 核心句与表达

| 歌词 | 意思 / 知识点 |
|---|---|
| It's been a long day without you, my friend | 没有你，这一天很漫长；`It's been` = It has been |
| And I'll tell you all about it when I see you again | 再见时我把一切都告诉你 |
| We've come a long way from where we began | 我们从起点一路走来，走了很远；`come a long way` 取得很大进步/经历很多 |
| Why'd you have to leave so soon? | 你为什么非得这么早离开；`why'd` = why did |
| I know you're in a better place | 我知道你去了更好的地方（委婉说去世） |
| Those were the days hard work forever pays | 那些日子，努力永远有回报；`those were the days` 怀念过去 |
| How could we not talk about family when family's all that we got? | 家人是我们仅有的一切，怎么能不谈家人 |
| Everything I went through you were standing there by my side | 我经历的一切，你都站在我身边；`go through` 经历（困难） |
| And now you gonna be with me for the last ride | 现在你将陪我走最后一程；`gonna` = going to |
| First you both go out your way | 一开始你们都主动付出；`go out of your way` 特意、不怕麻烦 |
| And the vibe is feeling strong | 氛围越来越强；`vibe` 氛围、感觉 |
| And what's small turn to a friendship | 小小的接触变成友谊 |
| A friendship turn into a bond | 友谊变成牢固的纽带；`bond` 纽带、羁绊 |
| And that bond will never be broke | 那纽带永远不会断；口语里用 `broke` 代替 `broken` |
| Then the line will never be crossed | 那条线永远不会被越过；`cross the line` 越界 |
| When that line had to be drawn | 当必须划清界线时；`draw a line` 划界 |
| So let the light guide your way | 让光指引你的路 |
| Hold every memory as you go | 走的时候带走每一段回忆 |
| And every road you take will always lead you home | 你走的每条路都会带你回家 |

### 口语点
- `gonna` = going to；`why'd` = why did；`you were` 在口语里常弱读。
- `family's all that we got` = family is all that we have got.
- 歌词语法不严格，`bond will never be broke` 规范写法是 `broken`；学唱可以，写作别照抄。

来源：2026-11-05

## 四、英文 Rap 与嘻哈文化

- Rap 的核心不是「快」，而是 **flow（节奏流）+ 押韵 + 叙事**。入门先选语速适中、叙事清楚的歌，不要一上来挑战最快语速。
- 常见练习路径：
  1. 先读歌词，查俚语和文化背景；
  2. 跟读副歌，抓重音和节奏；
  3. 逐句跟主歌，先慢速再原速；
  4. 录音对比，重点听自己哪里「吃掉」了辅音。
- 文化背景：hip-hop 起源于 1970 年代纽约布朗克斯区，包含 DJ、MC（说唱）、涂鸦、街舞四大元素；很多歌词里的 `hood`、`ghetto`、`beef`、`diss` 都有特定文化含义。
- 来源：2026-11-05

## 五、语气与场合速查

| 表达 | 粗俗度 | 适用场合 |
|---|---|---|
| kick ass | 中 | 朋友间夸人、非正式 |
| suck | 中低 | 日常吐槽 |
| LMAO | 低（网络） | 聊天、社交媒体 |
| get lost! | 高 | 生气时，慎用 |
| chrome off a trailer hitch | 高（成人向） | 不建议主动使用 |
| play it by ear | 无 | 全场合 |
| knockoff | 低 | 购物、日常 |
| catfish | 低 | 网络、情感话题 |
